# Screen Bible Addendum (Screen A)

**Status: PROPOSED. Every rule in this file is pending council ratification.** It applies to screen material only (beat sheet, teleplay, shot list, storyboard prompts, score plan). The comic stays bound by every existing canon file, unchanged. This file edits no existing file and adds no canon by itself.

**Location.** `README.md`, `11_MASTER_INDEX.md`, `production/README.md` and `bots/` define no location for screen material. This addendum therefore uses `screen/SCREEN_BIBLE_ADDENDUM.md`, with per-episode files under `screen/S1E01/`. (PROPOSED)

**Labels used here.**
- **CARRIED** = a rule taken from an existing file. Each one cites its file:line, and the existing file wins over this one if they ever differ.
- **PROPOSED** = a new screen-only rule. It is not canon until the councils ratify it.

**Precedence (CARRIED).** Every house mode inherits the fidelity protocol: `03_TONE_SPECS.md` L7 reads "All modes inherit `00_FIDELITY_PROTOCOL.md`". The lore bible defers the same way: `05_LORE_BIBLE.md` L5 reads "Where this file and those disagree, those win." This addendum sits under both.

### 1.2 Rule 3 on screen (PROPOSED, screen-only)

The comic rule, unchanged: `00_FIDELITY_PROTOCOL.md` L7 is headed "Bubbles." and reads "Short. One punchline per panel. No monologues in the bubble; strategy lives in the caption."

The **comic stays bound** by rule 3. Every comic panel, bubble and caption keeps the one-punchline limit. The extension below is for screen use only and never flows back into comic files.

- **S-D1 (PROPOSED).** A screen scene may hold more than one exchange of dialogue. A scene is not a panel, so rule 3's one punchline per panel limit does not cap the line count of a scene.
- **S-D2 (PROPOSED).** Each scene still has at most one punchline, and it should land on a canon line where the scene contains one (see §2).
- **S-D3 (PROPOSED).** No monologues on screen either. This keeps rule 3's spirit and the lore rule at `05_LORE_BIBLE.md` L139: "never as a monologue in a bubble". Proposed bound: no single speech longer than two short sentences.
- **S-D4 (CARRIED, voice).** Ra-Thor stays as written at `09_CHARACTER_BIBLE.md` L5: "Voice in bubbles is dry, short, slightly fond. Never lectures." New Ra-Thor lines stay short and dry. (Bound: CARRIED; applying it to screen lines: PROPOSED)
- **S-D5 (CARRIED).** Catch lines are not stacked: `09_CHARACTER_BIBLE.md` L7 reads "Catch lines, rotate, do not stack:". One catch line per scene at most. (Per-scene reading: PROPOSED)
- **S-D6 (CARRIED).** The councils speak only in four-word lines: `09_CHARACTER_BIBLE.md` L28 reads "They murmur in four-word bubbles. They do not outvote the Gate."
- **S-D7 (CARRIED).** The Founder never speaks: `05_LORE_BIBLE.md` L24 reads "Never on panel and never in a bubble." On screen this means no Founder voice, voice-over or line. (Screen reading: PROPOSED)
- **S-D8 (PROPOSED).** Strategy that the comic puts in captions goes into on-screen dossier title cards, never into speeches. Title cards follow the caption rules: TOLC only (`05_LORE_BIBLE.md` L35, "Captions and bubbles say"), and no numbers or names for the gates.
- **S-D9 (CARRIED).** The armor is the face, so there is no lip-sync and no mouth. `09_CHARACTER_BIBLE.md` L5 reads "The armor is the face. Visor slit is the only expression". Dialogue is staged on the visor slit, as `01_VISUAL_STYLE_GUIDE.md` L18 does for the comic: "tail aimed at the visor slit even though the mouth is hidden". (Screen staging: PROPOSED)

## 3. Marking new material

- **M1 (PROPOSED).** Every new line, beat, shot, location detail, prop or cue in screen material carries this exact tag: `PROPOSED CANON — pending council ratification`.

## 6. Screen formatting standard (PROPOSED)

- **F1.** Teleplays use standard screenplay format:
  - scene headings in caps (INT. or EXT., location, time of day);
  - action lines in the present tense;
  - character cues in caps above the dialogue;
  - parentheticals used sparingly;
  - transitions only where needed.
- **F2.** 12-point monospaced type, one page to roughly one minute of screen time.
- **F3.** House additions, each on its own line:
  - `TITLE CARD:` for dossier captions, verbatim when canon;
  - `MUSIC:` for cues;
  - `SFX:` for diegetic sound;
  - the canon or PROPOSED CANON tag from §3.
- **F4.** Beat sheets use a cold open, four acts and a tag, per the councils' Screen plan. Each beat cites its source panel or carries the PROPOSED CANON tag.
- **F5.** Shot lists and storyboard prompts keep the comic prompt stem's content (`01_VISUAL_STYLE_GUIDE.md` L26) and the S1E01 set add-on (`episodes/S1E01_THE_RIBBON_CLAUSE.md` L13), with frame-for-frame Rejects.
